# 2026.308.2335 — fix(image): build FROM the published base so the publish pushes only this image

## Summary

**Head `ced6445d69bf673aea3150192de0a823c647bd2a` — 4 files, +43/−13.** Fixes the publish
failure that left the first tag without an image: the image now builds FROM the **published
base OCI image** instead of importing its source, so `--push` has exactly one image to push —
this repo's own.

**The defect, measured.** `charly box build <box> --tag <tag> --push` applies `--push` to
every image in the resolved chain. This repo imported `pod-crabbox` (which imports
`distro-cachyos` and `distro-arch`), so the publish run `41895678841` tried to push
`ghcr.io/opencharly/arch:2026.308.1917` with this repo's `GITHUB_TOKEN` and died:

```
#8 ERROR: failed to push ghcr.io/opencharly/arch:2026.308.1917:
   denied: permission_denied: write_package
```

The token owns this repo's package only; the base repo owns `arch`/`cachyos`/`pod-crabbox`.
Result: `ghcr.io/opencharly/pod-crabbox-systemd:2026.308.1917` does **not** exist, so
image tag ≠ git tag. Filed as **opencharly/.github#279** (root fix: `--push` must push only
the requested box).

**The fix.** `base: ghcr.io/opencharly/pod-crabbox:2026.307.1828` — the same release the
import pin named, now consumed as the published artifact it is. The build pulls exactly that
tag and pushes only `pod-crabbox-systemd`. An OCI base does not carry its candy chain across
the boundary, so the image declares its CachyOS `distro:` chain, restates the inherited lease
port (`2222`), and probes the inherited contract in three new checks. The copied caller's
header now attributes the `v2026.307.1759` history to `pod-crabbox`, which is where it is true.

| file | what it is |
|---|---|
| `charly.yml` | the external `base:`, the `import: []` (no chain), and the declared `distro: [cachyos, arch]` |
| `candy/systemd-init/charly.yml` | `port: [2222]` and three inherited-contract checks (sshd/bootstrap/ready, the `crabbox` user, the 2222 drop-in + `sshd -t`) |
| `.github/workflows/image.yml` | the copied caller: only the history sentence changes, now attributed to `pod-crabbox` |
| `AGENTS.md` | the base is a pinned OCI artifact, not an import; why the external form is required by the publish path |
